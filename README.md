# 🛶 Сплавы — планировщик водных походов

Веб-приложение для планирования сплавов по рекам **Пермского края**: каталог рек, маршруты, меню, продукты, снаряжение, бюджет, погода и экспорт плана.

## Возможности

- **25 рек** с описанием, фото, сложностью и сезоном
- **3 типа маршрута** на каждую реку: экспресс, классический, расширенный
- **6 пресетов меню** + конструктор своего меню с шаблонами
- **Автоматический расчёт** продуктов (вес, калории, стоимость)
- **Списки снаряжения** по категориям
- **Бюджет** с разбивкой по статьям
- **Прогноз погоды** (Open-Meteo) и рекомендации по одежде
- **Экспорт**: печать, PDF, CSV, Excel, JSON

## Быстрый старт

Приложение — статический сайт, сервер не обязателен.

### Вариант 1: открыть файл

Откройте `index.html` в браузере. Для полной работы планировщика перейдите по ссылке «Открыть планировщик».

### Вариант 2: локальный сервер

```bash
# Python 3
python -m http.server 8080

# или Node.js (npx)
npx serve .
```

Затем откройте [http://localhost:8080](http://localhost:8080).

## Использование планировщика

1. Выберите реку в каталоге или в форме параметров.
2. Укажите количество участников, дней, дату и тип меню.
3. Выберите маршрут — план обновится автоматически.
4. Просмотрите маршрут, меню, продукты, снаряжение и бюджет.
5. Экспортируйте план или сохраните JSON для последующей загрузки.

## Технологии

- HTML5, CSS3 (CSS-переменные, тёмная тема)
- Vanilla JavaScript (IIFE-модули, без фреймворков)
- [Open-Meteo API](https://open-meteo.com/) для прогноза погоды
- LocalStorage для темы и шаблонов меню
